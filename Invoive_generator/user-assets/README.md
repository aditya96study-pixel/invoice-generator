# Your images go here (all optional)

Put these files in this folder before starting the build. Anything missing simply stays switched off in the app and can be added later from Settings.

| What | File name (suggested) | Tips |
|------|----------------------|------|
| Owner signature | `signature.png` | Sign with a dark pen on plain white paper, photograph it straight-on in good light. |
| Business stamp | `stamp.png` | Stamp on plain white paper, photograph straight-on. |
| UPI details | `upi.txt` | Write the UPI ID (e.g. `name@okaxis`) and the payee name exactly as the bank shows it. The app creates the QR code itself, with the exact amount filled in. If you'd rather use your existing QR, add a photo of it as `upi-qr.png`. |
