# Proposed logo

`logo-preview.png` shows all three versions.

**Idea:** a road stretching to the horizon forms the letter **A** (for Amitabh), with the lane markings in the middle and a rising sun at the top — travel, early starts, the open road. Navy (`#14213D`) for trust and formality, marigold (`#F5B82E`) for warmth; the same marigold is used in the Marigold Trip Bill theme.

| File | Use |
|------|-----|
| `logo-icon.svg` | App launcher icon (convert to adaptive icon: navy background layer + road/sun foreground layer), splash screen, small logo on invoices |
| `logo-full.svg` | Wide logo with wordmark for invoice headers, the app's top bar and the About screen. Text uses Montserrat — during the build either bundle Montserrat or convert the text to paths so it looks identical everywhere |
| `logo-mono.svg` | Black-only version for the Print Saver theme and B/W printing |

Not final — the user can ask for changes when the build starts.
